# 🚀 CI/CD Pipeline
I am testing
A modern Java-based web application built to demonstrate a complete DevOps CI/CD pipeline using **Jenkins**, **SonarQube**, **Nexus**, and **Slack**. The pipeline automatically builds, tests, analyzes, and deploys your app — with notifications every step of the way.

---

## 📌 Project Overview

This project is designed to simulate a real-world continuous integration and delivery workflow using the following:

- 🔧 **Java 17** & **Maven**: For compiling and packaging the web application
- 🔁 **Jenkins**: Automates the entire pipeline from code to deployment
- 🔍 **SonarQube**: Performs code quality and security analysis
- 📦 **Nexus Repository Manager**: Hosts the built `.war` artifacts
- 💬 **Slack**: Sends real-time build notifications
