# VProfile Web Application CI/CD Project

This project demonstrates a full CI/CD pipeline using:
- Jenkins
- SonarQube
- Nexus
- Slack

## Pipeline Features
- Automatic build on GitHub push
- Code quality check using SonarQube
- Artifact deployment to Nexus Repository
- Slack notifications on build status

## Technologies
- Java 11
- Maven
- Jenkins
- SonarQube
- Nexus OSS
- Slack

## How to Deploy
1. Push changes to GitHub
2. Jenkins triggers build
3. Code is analyzed by SonarQube
4. Artifact is deployed to Nexus
5. Slack channel is notified
